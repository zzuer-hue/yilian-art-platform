# 艺链 · 本地展示版

最新界面已完成公众展示优化：首页、作品库、创作工作台、详情、查询、创作者、个人空间与订单均统一设计。更新内容和验收见 `设计更新.md`。

根据《艺链——元宇宙数字艺术品收藏平台》申报书与用户提供的 `yyds666_site` 前端完善的可运行本地版本。保留原站深色 / 粉红渐变视觉、Logo、首页背景、作品图片和深浅色切换，并接入本地业务接口。

## 启动与访问

要求 Windows 已安装 Python 3.10 或以上，无须 npm、Maven、MySQL 或外网服务。

双击 `start.cmd`，脚本会在后台启动服务，并用默认浏览器打开 http://127.0.0.1:8877 。

也可在本目录执行：

```powershell
python server.py --port 8877
```

只监听本机 127.0.0.1，不开放局域网。使用前台命令启动时按 Ctrl+C 停止；使用启动脚本时执行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\stop.ps1` 停止。

## 操作路线

1. 首页 → 发现作品：分类筛选、搜索作品 / 创作者 / 作品编号 / 文件或记录哈希、排序、展厅模式。
2. 点击作品 → 体验收藏 → 创建订单 → 勾选说明 → 确认演示购买 → 我的收藏。关闭确认框后可从“我的订单”继续操作或取消待确认订单。
3. 发布作品：选择 PNG/JPEG/WebP（最大4MB），填写介绍、展示价、发行量并确认发布权利。提交后获得作品编号和本地记录哈希。
4. 存证查询：输入作品编号（如 `YL-001`）或完整哈希。检查文件摘要、全局记录连续性，查看发布 / 收藏时间线，下载 JSON 存证。
5. 创作者：展示作品数和本地收藏数，并可跳转到该创作者作品。
6. 开启体验：默认无需注册即可浏览，操作时可自动开启体验身份。也可以注册本地账号、登录或退出。注册账号使用 PBKDF2-SHA256 保存密码摘要；无邮箱验证与密码找回服务。

## 已实现与真实接入边界

| 申报书方向 | 当前实现 |
| --- | --- |
| 注册、登录 | 可选本地账号与体验身份、HttpOnly 会话、请求来源与 CSRF 检查 |
| 创作者发布 | 图片上传、内容摘要、元数据、发行量、卡片实时预览 |
| 作品搜索 | 名称、创作者、编号、文件哈希、记录哈希；分类与排序 |
| 收藏交易 | 无实际扣款的演示收藏；服务端校验数量、每身份限一份、重复请求不重复记账 |
| 订单管理 | 创建待确认订单、继续确认、取消、完成状态、按当前身份查询订单；确认后与收藏和轨迹联动 |
| 作品存证 | SQLite 事件日志与前序哈希链接，文件 SHA-256，校验与存证 JSON 下载 |
| 创作者排行 | 当前本地作品与演示收藏数实时统计 |
| 元宇宙展示 | 线上二维展厅；未实现三维场景或 VR |
| FISCO BCOS / 合约 / WeBASE | 尚未接入，缺少节点、SDK 配置与合约源码 |
| 微信、支付宝支付 | 未启用；不会使用原包里的商户密钥或向支付平台发送交易 |

本地哈希记录不是 FISCO BCOS 链上交易，也不是不可被本机管理员篡改的分布式账本或法律权属证明。文件可以被复制；哈希校验只能检查内容与当前记录的一致性。收藏不自动转让著作权。

## 原始资料核查与处理

已核查原包全部343个条目及78个 JAR 的目录：

- `demopay/`：215个文件，其中41个 Java 文件，包含商品查询、订单、微信支付与退款模块。
- `demopay_jar/`：78个 JAR；`demopay.jar`为编译后的支付服务，其余主要为运行依赖。
- 没有业务 HTML、JS、CSS、Vue/React 工程、SQL 初始化文件或 FISCO BCOS 合约源码。
- Swagger 依赖自带 HTML/JS/CSS，只是接口文档与调试界面，不能作为艺链业务首页。

随后收到的 `yyds666_site` 包含22个 HTML 页面、样式、脚本和图片。其首页、Logo、渐变背景和作品素材已用于本版；原件副本保存在 `reference-front/`，不由本地服务公开托管。用户提供的原始目录未被修改。

原前端的商品支付编号写死、表单依赖缺失的 PHP、上传页缺失、WeBASE 指向旧内网地址；这些入口在本地版中已替换为对应业务流程。原列表 / 详情 / 登录 / 注册等 HTML 地址也可跳转至新页面。原站无关的模板新闻、钱包营销与订阅入口没有启用。

本版为沿用原站视觉和素材后重构的业务前端与 Python 本地后端，并未假称原 Java 支付模块已经启动或集成。原始后端解压文件保留在工作目录 `work/source`；本交付目录未包含商户私钥、原始支付配置或依赖 JAR。

如果后续拿到链合约和节点配置，可以替换存证适配层。真实支付需要完整商户配置、服务器回调验签与对账，不能用浏览器按钮代替支付成功确认。

## 文件与数据

- `public/index.html`：HTML 页面入口；`public/app.js`、`public/style.css`、`public/original-theme.css`：业务前端交互和原站主题适配。
- `public/static/`、`public/img/`：用户提供的原站素材；内置6件作品沿用原站标题、图片和展示价，创作者名称、发行量与记录为本地样例，不代表真实在售数据或原作者身份。
- `public/assets/`：补建时生成的矢量素材与图标，供后续调整使用。
- `server.py`：Python 标准库 API、会话、上传、收藏、查询、校验、静态文件服务。
- `data/yilian.sqlite3`：持久化数据；`public/uploads/`：上传图片。备份时两者需一起保存。
- `start.cmd` / `start.ps1` / `stop.ps1`：本地启动与停止脚本。

不要通过双击 HTML 或 `file://` 访问来替代启动服务，交互功能需要本地 API。首次启动自动生成样例数据。体验身份依赖浏览器 Cookie，退出或清除 Cookie 后不能通过密码恢复；希望长期使用请先注册本地账号。体验身份数据不会自动迁移到注册账号。

已使用本机 Chrome 实际验证搜索、详情、创建订单、确认购买、个人收藏、订单列表、存证查询、图片上传发布、创作者联动，以及8个主要页面的手机宽度布局。结果见 `browser-checks.txt`；预览见 `preview-home.png`、`preview-mobile.png`。
